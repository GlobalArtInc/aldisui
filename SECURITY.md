# Security Policy

## Supported versions

Only the latest release of Aldis receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/GlobalArtInc/aldisui/security/advisories/new).
Please include a clear description, steps to reproduce, and any relevant logs or payloads.

We ask that you do not disclose the issue publicly until a fix has been released.

## Scope

This policy covers Aldis itself and the containers and packages published from this repository.
It does not cover third-party plugins or local modifications. Vulnerabilities inherited from
upstream Semaphore UI should also be reported to that project.
